# Quick Usage Examples

Read with `sf-review mode:browser/SKILL.md`. Procedure lives here.

## Quick Usage Examples
```bash
# Test current branch changes (auto-detects port)
/sf-review mode:browser

# Test specific PR
/sf-review mode:browser 847

# Test specific branch
/sf-review mode:browser feature/new-dashboard

# Test on a specific port
/sf-review mode:browser --port 5000
```
